## Context

`Vnum.GetAll<TVnum>()` (`src/VnumEnumeration/Vnum.cs`, line 154 after BL-0002; it now also carries the `DynamicallyAccessedMembers` annotation BL-0003 added, which must stay) is declared as `IEnumerable<TVnum>`, but the object it returns is the cached `ReadOnlyCollection<TVnum>`; `VnumDiscoveryTests.GetAll_Result_Should_Be_Read_Only` casts to `IList<TVnum>` to prove it. Callers that need `Count` or an index call `ToList()` and allocate a copy of a collection that is already a cached list.

## Scope

- Change the return type of the parameterless `GetAll<TVnum>()` to `IReadOnlyList<TVnum>`. The predicate overload stays `IEnumerable<TVnum>` (it is a `Where`).
- Source-compatible for every consumer (`IReadOnlyList<T>` is an `IEnumerable<T>`), but binary-breaking (the return type is part of the method signature), so it ships in a major version.
- Update the README "Lookup" example and the test that currently casts.

## Acceptance criteria

- [ ] `GetAll<TVnum>()` returns `IReadOnlyList<TVnum>`; `GetAll_Result_Should_Be_Read_Only` uses the typed interface instead of a cast
- [ ] README "Lookup" shows the new type
- [ ] `dotnet build VnumEnumeration.slnx` and the full test suite pass
