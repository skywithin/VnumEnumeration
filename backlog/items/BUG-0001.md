## Summary

`Cache<TVnum>.Build` in `src/VnumEnumeration/Vnum.cs` publishes the lookup table only when every discovered public static field is non-null (the `values.All(v => v is not null)` guard, line 250 at the time of filing). The guard exists to detect a lookup made from inside the type's own static initializer, where later fields are still unassigned (see `ReentrantVnum` in `tests/VnumEnumeration.Tests/Data/TestData.cs`). A field that is legitimately null looks identical:

```csharp
public sealed class Status : Vnum
{
    private Status(long value, string code) : base(value, code) { }

    public static readonly Status A = new(1, "a");
    public static readonly Status? None = null;   // sentinel; the table is never cached
}
```

For such a type the table is rebuilt with `GetFields` and `GetValue` on every call to `GetAll`, `FromValue`, `FromCode`, `FromEnum` and the `Try*` variants, for the lifetime of the process, with no warning.

## Evidence

Probe console app, Release build, .NET 10, 200,000 `TryFromValue` calls after warm-up (2026-10-26):

| Type | Time |
|---|---|
| With one null public static field | 174 ms |
| Without | under 1 ms |

## Expected behaviour

A null field must never cause a permanent cache miss. Pick one policy and document it in README under "Instance discovery":

1. Forbid null fields. `Build` throws `InvalidOperationException` naming the type and field. Lookups from inside the type's static initializer become unsupported, and the `ReentrantVnum` test changes to assert the exception. Simplest and fully deterministic.
2. Detect reentrancy properly. When a null is seen, walk the stack (`new System.Diagnostics.StackTrace(false)`) for a `.cctor` frame whose declaring type is `TVnum`. On that thread, return the partial table without caching (today's behaviour). Otherwise the null is genuine: skip the field and cache. The walk only runs when a null is present, so the normal path is unchanged.

## Constraints

- The hot path (`Volatile.Read` then a dictionary lookup) must not gain any work.
- Aliased fields (`AliasedVnum.Default = One`) must still count as one instance.
