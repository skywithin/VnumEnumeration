## Context

Discovery is `DeclaredOnly`, so a property typed as an abstract intermediate Vnum has no instances of its own:

```csharp
public abstract class Shape : Vnum { protected Shape(long v, string c) : base(v, c) { } }
public sealed class Circle : Shape { /* instances live here */ }
public class Holder { public Shape? S { get; set; } }
```

Probe on 2026-10-26: deserializing `{"S":"a"}` into `Holder` throws `JsonException: 'a' is not a valid code for Shape. Valid codes: ` with an empty list. The behaviour is by design, but the message does not say why, and the empty list reads like a bug in the library.

## Scope

- In the private `InvalidCode` helper (shared by `Read` and `ReadAsPropertyName` since BUG-0002), when `GetAll<TVnum>()` is empty, throw a `JsonException` that names the cause: the type declares no public static fields of its own type, and properties must be typed as the concrete Vnum type because instances are discovered on the declared type only.
- Optionally the same wording in the `NotFound` message in `Vnum.cs`; keep to the converter unless it is cheap.
- README "Instance discovery": one sentence on abstract intermediate types.
